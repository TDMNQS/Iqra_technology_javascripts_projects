# JavaScript Project Suite 

Nine working JavaScript projects created by **Numan Qureshi** for the Iqra Technology Academy assignment.

## Projects 

1. OTP generation and verification with a countdown timer
2. Dynamic customer capture form for individuals and businesses
3. Budget management system with editable category allocations
4. Task scheduler with due dates, priorities, editing, and deletion
5. Sortable and filterable product table
6. Employee record management with CRUD and search
7. Pagination for 100 records with 10 records per page
8. Expense tracker with categories and spending summaries
9. Registration form validation with country-to-currency mapping

## Technology 

- Semantic HTML5
- Responsive CSS3
- Vanilla JavaScript
- Browser local storage for the data-driven projects

## Run locally

Open `dist/index.html` in a browser, or serve the `dist` folder with any static web server.
